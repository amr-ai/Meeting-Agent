2. Weekly Cost per Team

Using 52/12 = 4.333 weeks/month, each team uses 21.667 bot-hours and 1,300 meeting minutes monthly. Each LiveKit room has two connections: the Recall bridge and the worker. Therefore, budget 2,600 WebRTC minutes/team/month. Other human participants in Meet do not each create a connection to this LiveKit room. 3. Listening, Speaking and Screen Understanding

Recall bills bot runtime whether Khaled speaks or stays quiet; waiting-room time can add runtime. LiveKit bills connection usage. Gemini bills input, output and context tokens. The application continues receiving audio while Khaled is quiet, and its response gate can suppress audio after generation. Unheard generated audio can therefore still incur charges.

Gemini Live rates per million tokens: audio input $3; image/video input $1; text input $0.75; audio output $12; text/thinking output $4.50. Flash-Lite input is $0.30 and output is $2.50. Google documents context re-billing and transcription text charges. Context compression is enabled in the project, but it is not a spending cap. Model pricing · Billing rules

Images are sent to Gemini only when requested. However, shared-screen video travels from Recall to the server while screen sharing is active, even before a question. Image-analysis charges and video-transfer charges are separate. Screenshot cost depends on token usage, context and the response. The Zubenelgenubi voice does not require a separate TTS subscription.

4. Concurrent Meeting Capacity

  • LiveKit: 1,000 connections allow a theoretical 500 two-party rooms, not a guarantee that the workers or Gemini can handle 500 meetings. Ship's 20 hosted-agent-session limit applies to agents deployed on LiveKit Cloud, not the self-hosted workers costed here. Moving workers to LiveKit Cloud requires a different hosting calculation.
  • Recall: check the workspace's actual ad-hoc concurrency limit in its dashboard. Recall recommends scheduling bots more than 10 minutes in advance. The current launcher joins immediately and does not send join_at; purchasing a plan does not add scheduling to the application. Scheduling · Ad-hoc limits
  • Gemini: quotas apply per project, not per API key. Additional keys do not multiply capacity. Confirm the quota needed for the expected simultaneous meetings.
  • Application: the API and screen state are currently local. Multiple replicas require a deployment and state-management design, plus load testing.

5. Additional Costs and Recommendation

Recall storage is free for the first seven days, then $0.05 per recording-hour retained for 30 days. This accumulates according to retention policy; deleting local transcripts does not delete provider recordings. LiveKit transfer is included up to the plan allowance, while ngrok overages are separate. For scale illustration only, a 1Mbps screen stream over five hours is about 2.25GB/team/week before overhead; actual bitrate varies.

Recommendation: retain LiveKit and start with one shared Ship plan, Recall PAYG with a volume quote as usage grows, Gemini Paid API and Tavily PAYG. Use ngrok PAYG for the current deployment and evaluate direct HTTPS on company hosting for production. For 10 teams: $5.53/team/week base, plus Gemini, hosting and additional usage.
